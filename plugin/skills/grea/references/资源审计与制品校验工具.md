# 资源审计与制品校验工具

本页维护资源/制品工具的输入、输出与失败边界。先用[工具选择](工具选择与调用.md)定位ID，再按[接口合同](接口调用与证据记录.md)的当前describe-tool/help执行。`GREA_ROOT`指实际安装根目录；执行归属看registry.delegate，项目内容留项目，输出不写Skill包。

新能力接收与测试要求统一见[脚本晋升](项目脚本沉淀与工具晋升.md)。下面是兼容ID的有限合同，不是所有样本/平台已验收声明。

## 当前工具

命令示例中的路径替换为实际输入和全新输出，不以源码目录为运行前提。

| 脚本 | 来源 / 依赖 | 输入与输出 | 边界 |
| --- | --- | --- | --- |
| `unpack_xapk` | Python 3.9+ 标准库 | XAPK → Reference、APK清单、各包独立 assets/libil2cpp、源SHA-256 | 不安装、合并分包或执行Android代码；只展开顶层APK的所选内容，不是反编译器 |
| `video_sheet` | Python 3.9+、Pillow、ffmpeg | 本地录像 → 标注近似采样时间的联系表 | 裁剪/范围/采样率可配置；不控制设备，时间不是原帧PTS或事件时间 |

```sh
"$GREA_ROOT/bin/grea" legacy unpack_xapk /path/game.xapk --output /tmp/game-extract
"$GREA_ROOT/bin/grea" legacy video_sheet /path/native.mp4 --output /tmp/native-sheet.jpg --start 0.4 --duration 2 --fps 8 --ffmpeg /path/to/ffmpeg
"$GREA_ROOT/bin/grea" legacy static_asset_copy --source /path/webgame --output /tmp/webgame-dist --map index.html=index.html --map src=src --map public/assets=assets
```

选择新的输出路径。视频 `--crop LEFT TOP RIGHT BOTTOM` 使用原视频像素，`--columns`、`--width` 只控制联系表排版；完整参数见各工具 `--help`。

## 兼容与结果

旧工具ID和别名保留，实际执行模块以registry为准。迁移旧输入时核对是否依赖合并解包目录、固定裁剪或输出名，不覆盖旧资产。抽帧联系表的近似采样时间不能替代原录像PTS/事件时间；文件校验不能证明内容语义。

规则/事件差分与ELF常量读取统一见[规则差分工具](规则差分与数值纹理工具.md)。

## Unity 导出依赖审计

```sh
"$GREA_ROOT/bin/grea" legacy unity_dependency_audit --assets /path/export/Assets \
  --root GameObject/Example.prefab --root Scenes/Example.unity --output /tmp/new-closure-report.json
```

输出父目录须存在，拒绝覆盖文件、写入源目录、根路径越界或符号链接。默认单个文本扫描上限 32MiB，可用 `--max-text-mib` 调整；超大或二进制文件列为未扫描，不静默算完整。退出码 0=静态扫描完成，1=清单已生成但有缺口，2=输入/执行失败。0 不保证动态加载、内建 GUID、脚本身份或运行可见性正确。

检查器将 `.cs/.dll` 全部列入待审排除项，并不认定它们全是空壳；实际导入前分类原实现/类型空壳/运行时依赖。文本 GUID 闭包不能替代 AssetDatabase 二次核验、二进制 PPtr 解析和 Resources/Addressables 动态加载调查。

## 媒体与交付包

| 脚本 | 输入/依赖与用途 | 输出及边界 |
| --- | --- | --- |
| `video_manifest` | 一个或多个本地录像；ffprobe，`--decode`时另需ffmpeg | 新JSON：SHA-256、字节数、时长、尺寸、帧率元数据、音轨及按需解码。0检查通过，1媒体问题已记入报告，2输入/工具错误。不是录屏器，不证明画面/声音内容或事件时序 |
| `verify_payload_tree` | 期望目录与已释放目录；Python标准库 | 相对文件名、尺寸、SHA-256的缺失/多余/变更报告。0一致，1差异，2输入错误。默认精确比较，显式exclude同时应用两侧并写入报告；不解包、不执行文件 |
| `package_windows_portable` | 已构建Windows目录、相对入口、标题、架构；makensis、7zz | 新EXE和同名`.manifest.json`。私有暂存快照→NSIS编译→7-Zip测试/释放→逐文件校验→独占发布。0仅表示包体通过，2失败；不运行游戏、不安装工具、不验证Windows兼容性 |

```sh
"$GREA_ROOT/bin/grea" legacy video_manifest /path/recording.mp4 \
  --output /tmp/new-video-report.json --require-audio --decode
"$GREA_ROOT/bin/grea" legacy verify_payload_tree /path/build /path/extracted/Game \
  --output /tmp/new-payload-report.json
"$GREA_ROOT/bin/grea" legacy package_windows_portable --payload /path/windows-build \
  --entry Game.exe --machine x64 --title "Game Preview" --output /tmp/new-game.exe
```

输出父目录需存在，默认拒绝覆盖旧产物；目录工具拒绝根/后代符号链接和输入内输出。打包器另检查入口PE架构、Windows非法/保留名称和大小写冲突；通过参数指定外部程序，不自动安装。文件清单列出显式排除项，不默默漏掉运行依赖。

目录校验只比较普通文件，不比较ACL/时间戳或空目录。打包器当前不转发命令行参数；已实测x64，x86路径未做运行验收。

打包器只处理自己生成的NSIS包，不是任意不可信EXE解包器。私有临时目录只在子游戏退出后由NSIS正常清理；调用方确认存档在外部用户目录。启动器需要实际目标系统验证，签名与平台发布要求另行处理。输入或编译失败不会替换旧包；极晚的磁盘写入失败可能留下本次新文件，核对后换新输出，不自动清除用户目录。

## Unity 资产迁移台账与预检

| 子命令 | 输入与输出 | 退出码含义 |
| --- | --- | --- |
| snapshot | Assets目录 → 文件/目录GUID、内容/meta哈希、缺失/重复/orphan meta、跨平台路径冲突、空目录和命名候选 | 0无身份问题，1有问题待审，2输入/I/O错误；空目录和疑似哈希名只是候选 |
| compare | 两份该工具快照 → 按GUID关联的移动、增删、内容/meta变化及同路径GUID替换 | 0未变，1有变化或待审问题，2无法可信比较；正常迁移也会返回1，不代表迁移失败 |
| check-plan | 快照与文件级迁移清单 → 源GUID、目标碰撞/父路径、Windows名称和退出理由预检 | 0静态预检通过，1待审，2输入错误；通过不代表可删除或已获授权 |

```sh
"$GREA_ROOT/bin/grea" legacy unity_asset_ledger snapshot --assets /path/project/Assets --output /tmp/assets-before.json
"$GREA_ROOT/bin/grea" legacy unity_asset_ledger snapshot --assets /path/project/Assets --output /tmp/assets-after.json
"$GREA_ROOT/bin/grea" legacy unity_asset_ledger compare --before /tmp/assets-before.json --after /tmp/assets-after.json --output /tmp/assets-delta.json
"$GREA_ROOT/bin/grea" legacy unity_asset_ledger check-plan --snapshot /tmp/assets-before.json --plan /tmp/file-moves.json --output /tmp/plan-review.json
```

清单路径相对Assets，不带Assets前缀；GUID应来自快照。例如：

```json
{
  "schema": "unity-file-move-plan-v1",
  "moves": [
    {"from": "UI/old-icon.png", "to": "UI/Sprites/PauseButton.png", "guid": "11111111111111111111111111111111"}
  ],
  "retire": [
    {"path": "Legacy/OldPanel.asset", "guid": "22222222222222222222222222222222", "reason": "Reviewed callers migrated; backup and Editor dependency checks required"}
  ]
}
```

示例GUID不是执行值。目录整体移动须另外通过Editor规划；此预检仅接受文件项。大小写改名、交换路径和已占用目标不自动推断安全执行顺序，应先明确临时路径/阶段。输出必须是已存在父目录中的新文件，不能覆盖输入或写入快照指向的活动Assets。

工具拒绝资产根/后代符号链接，记录排除的常见OS缓存；合法中文不会被标为乱码。不能从哈希名自动生成业务名，也不能凭扩展名判断加密。快照不记录Unity对象name、子资源fileID、GUID动态加载或完整依赖，必须另做Editor回读。目录空不意味着没有图集/生成规则引用。

### 按迁移清单验收

```sh
"$GREA_ROOT/bin/grea" legacy unity_asset_ledger verify-moves --before /tmp/assets-before.json --after /tmp/assets-after.json --plan /tmp/file-moves.json --output /tmp/moves-result.json
```

仅接受非空文件 moves、空 retire；核对每项 GUID、内容和 meta 哈希、旧路径退出、Resources 相对键不变。0 为 planned_files_match，1 为 needs_review，2 为输入/I/O 错误。只核对提供的快照与清单，不读取当前工程；目录退休和清单外改动另用 compare，不验证 Unity 对象名/fileID、类型或运行时加载。

## 图片透明边缘检查

`image_alpha_audit` 是素材切分后的只读检查，不负责生成、抠图或修图。Python 3.9+，依赖当前锁定 Pillow。

```sh
"$GREA_ROOT/bin/grea" legacy image_alpha_audit --images /path/button.png /path/icon.png --require-transparency --output /tmp/alpha-result.json
```

输出 JSON 包含尺寸、源格式/模式、SHA256、alpha 包围盒和极值、透明/半透明像素数及不透明边缘统计。完全透明图片始终报问题；整张不透明仅在 require-transparency 下报问题。边缘统计只是诊断，不能判断主体锚点、灰边或按压态视觉是否正确。依赖不足或坏输入返回2；发现问题1；检查通过0。默认最多 20000000 像素，可显式调整 max-pixels；拒绝符号链接与覆盖输出。


## 静态文件映射复制

`static_asset_copy` 使用 Python 标准库，无 Node 依赖。它替代原静态文件复制脚本，保留 `--source`、`--output`、重复 `--map FROM=TO` 以及 JSON 的 output/mappings/validation 字段；原生调用成功退出 0，参数或复制失败退出 1。它不编译代码、不处理资源内容、不验证浏览器或游戏运行。

日常使用 `run-tool` 获取统一预算与回执；参数帮助使用 `grea legacy static_asset_copy --help`。输出必须是源目录之外的新目录或空目录，两者不能互为祖先。源资源路径和内容树中的符号链接、路径穿越及目标映射重叠会在写入前拒绝；正常输出路径别名按实际目录检查，不绕过输入/输出隔离。

输入为合作式本地文件系统；不是防恶意并发写入的沙箱，也不提供事务回滚。复制途中失败保留已写内容，检查原因后另选输出，不自动清空。新 Python 实现还拒绝 Windows 盘符映射和悬空输出链接，避免在不同平台误解路径。
