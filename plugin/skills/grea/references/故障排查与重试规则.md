# 流程 · 故障排查与重试规则

重复失败或测试与实玩冲突时，按症状选入口，先定位第一处缺口；不自动全量运行 doctor 或重做恢复。环境可疑时只核对相关工具，入口见 [工具清单](工具选择与调用.md)。

| 症状 | 先取得的证据 | 权威处理入口 |
| --- | --- | --- |
| 原界面资源似乎缺失/字段读不全 | 包哈希、导出索引、加载 getter、PPtr/MonoScript 与外部包 | [资源身份与类型树](../../grea-recover/references/提取与引用恢复.md)；不先自制替代 UI |
| 导出 C# 能编译但逻辑不对 | 方法体、metadata/方法地址、调用链与分支 | [代码恢复](../../grea-recover/references/Unity工程重建与恢复.md)；区分空壳与实现 |
| MCP 零工具、主线程/构建超时 | 目标项目、Pipeline、编译/重载状态、run-id/进程/报告时间 | [连接与执行](../../grea-develop/references/Unity编辑器连接与任务执行.md)；先查旧任务，勿盲重跑 |
| Prefab 激活但空白/缺图 | sprite.texture、图集、实际 Shader、相机与排序 | [实际显示](../../grea-develop/references/Unity界面还原与输入交互.md#unity-原工程恢复的显示检查)、[接入回读](../../grea-recover/references/Unity工程重建与恢复.md#shader-与-spine-接入回读) |
| Spine 局部、特效黑块或材质机制失效 | atlas/动画引用、活跃 Shader 属性、运行材质/遮罩 | [接入](../../grea-recover/references/Unity工程重建与恢复.md#shader-与-spine-接入回读)、[特效排错](../../grea-develop/references/Unity动画特效与事件时序.md#特效排错顺序) |
| 动画永不结束/短动画采不到中间帧 | 加载、焦点、timeScale、deltaTime、轨道/回调及事件时间 | [帧率前提](测试与结果交付.md#短动画与帧率前提)、[生命周期](../../grea-develop/references/Unity动画特效与事件时序.md)；不改生产时长迎合夹具 |
| 任务、扣费、重入或重载异常 | ID/字段、可见与可执行条件、实际存档路径和起点 | [玩法](../../grea-develop/references/规则与随机一致性.md)、[奖励边界](../../grea-develop/references/Unity动画特效与事件时序.md#奖励表现与流程边界) |
| 拖动滞后/松手继续转/截图有窗口但点击无效 | 输入队列、边沿、捕获、焦点、进程与构建ID | [输入与焦点](../../grea-develop/references/Unity界面还原与输入交互.md)；不直接改灵敏度或删除生产门禁 |
| 规则连体但无线、粒子存在却无效果 | 关系锚点、运行资源键、活跃实例、粒子及清理事件 | [运行绑定与关系表现](../../grea-develop/references/Unity动画特效与事件时序.md) |
| 命中卡顿/高内存 | 精确进程、堆/RSS、采样负载、分配/写盘/候选扫描 | [性能对照](../../grea-develop/references/Unity性能分析与优化验证.md)；用有界测试，不并发重跑全套 |
| 单EXE可解压但无法启动 | 目标架构/后端、完整payload身份、实机日志 | [构建交付](../../grea-release/references/游戏构建与版本发布.md)；包体检查不替代实机 |
| GUID 未变但类型整理不达标 | 实际导入类型、旧新路径与动态键，是否仅套父目录 | [类型目录](../../grea-develop/references/Unity工程目录与资产归类.md#类型归类表)、[迁移执行](../../grea-develop/references/Unity重构与资源迁移.md) |
| Editor 退出后设置/恢复对不上、Player 后台无结果、Mac Player 卡呈现 | 退出后磁盘回读、前后台状态、vSync/线程模式与构建ID | [原生执行常见陷阱](../../grea-develop/references/Unity编辑器连接与任务执行.md#原生执行常见陷阱)；不放宽断言或永久降画质 |
| provider 超时/崩溃（AssetRipper 等） | 版本、二进制与输入 SHA、耗时/预算、退出码 | 同上；无新参数或版本不重启试错，改走已冻结的批量结果 |
| 读取器行数少于原表/查找错位 | 原 lookup 签名与键组成、原表行数 | [数据表读取与查找键](../../grea-develop/references/规则与随机一致性.md#6a-数据表读取与查找键) |
| 同一脚本被复制成多个编号版本 | 参数差异、调用次数、是否通用 | [项目脚本沉淀与工具晋升](项目脚本沉淀与工具晋升.md)；参数化或提交 beaver/monkey 缺口 |
| 换皮风格相似但按钮形状不对 | 最新批准来源、本次是否指定页面独占裁片、实际制作输出 | [素材制作](../../grea-develop/references/游戏换皮与资源制作.md)；不混入已否定版本 |

## 工具执行的停线条件

发现目标/输入不匹配、关键引用或编译失败时，按 [执行契约](../../grea-develop/references/Unity编辑器连接与任务执行.md#编辑与长任务) 暂停依赖步骤，独立工作继续。新证据才能支持再次尝试；旧 PASS 或外层超时都不足以下结论。调查检查点见 [工作节奏](../../grea-develop/references/开发前检查与迭代.md)。

历史案例与当时状态归 [经验导航](开发复盘与规范更新.md#历史经验检索)，本页不维护项目进度。
