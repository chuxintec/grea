# 成组 Prefab 恢复与采用

用于完整页面、活动组或同类 Prefab 的批量恢复，以及已有项目发现布局/组件/图片恢复失真的整改。GREA负责人组织公开入口、固定候选和采用闭环，monkey负责恢复机制，beaver负责工程采用机制，项目主开发负责业务接线和实际画面。恢复的执行主体必须是 monkey 程序：依赖解析、层级/布局/组件/图片引用映射和原生 Prefab 文件生成由工具自动完成。Agent 提供输入并实际成组调用，可以分析源数据定位真实失败、修工具通用机制，再做采用和验收；分析报告、逐页人工推导或作者脚本不能替代工具转换。

## 批次输入与实际执行

1. 固定原包/来源版本、源引擎与目标 Editor、明确根 source ID；额外动态条目/容器/模板的已知 ID 只是提示，不是完整分母。由既有 monkey 能力计算根与资源、子 Prefab、图集/图片、字体、材质、组件和引用的完整依赖闭包，并注明动态加载依据与未解析项。
2. 确认最新**适用且已固定**的候选及精确提交/制品身份。其他来源路线的新版本不自动适用；默认发现、安装或候选版本登记不证明已经转换或采用。输入原件只读，输出与当前工程分离。
3. 必须经 GREA 公开恢复入口调用 monkey，成组生成纯转换候选，留实际请求、进程结果、输入/输出清单、来源映射和失败类别。可以使用已有分块事务，但同批根清单与来源身份保持。参数缺口由 GREA 做有限薄适配，转换机制由 monkey 修，不另造项目转换器。
4. 只导入受影响根与完整必要闭包，不为局部恢复全游戏重导；也不能只拿入口或几个静态子集代替整页。计划、lookup、IR、测试数量、exit0 或保存成功均不作为批量恢复完成。

## 三层对照与共因修复

逐批保留“同版本原始 Prefab/画面 → monkey 纯输出 → 项目采用态”三层身份及差异。先核编辑器直接查看的层级、RectTransform/锚点/缩放、布局约束、图片与九宫格/遮罩、文字字体/描边、材质、组件字段和资源引用；动态内容恢复原条目、容器与模板，不能用通用文字行、按钮或占位替代完整源 UI。主题和画面版本不同不能因同名资源而混用。

输入足够即运行转换；必要的动态模板/布局发现沉淀为通用工具能力，不扩展完整脚本恢复。恢复中间代码、映射、IR、中间 JSON 或 completed=true 都不是实际的 Unity `.prefab`；先消阻断共因并走原生导入，不等全部警告清零或无关打包。

纯输出中的共同布局、组件、图集或引用缺陷交 monkey 修机制，通过同一公开入口重现与消除，再成组更新受影响输出。工程采用共因交 beaver。禁止页面名/GUID 白名单、手改纯输出掩盖问题、在项目复制恢复算法。只复验本次失败和同机制相关样本，原失败证据保留。来源缺失、解析失败、采用失败和业务缺陷按[缺口归属](../../grea/references/故障排查与重试规则.md#先分清缺口归属)分开，不为补材料穷举全池。

## 先静态、后业务

采用前由项目主开发保全现有 WIP、GUID、存档和已验业务，停止继续扩展已被否定的自由拼贴作者，并核实际目标引用和[唯一写入来源](../../grea-develop/references/Unity脚本与生成契约.md#唯一生成源与退役)：旧生成器、集成脚本或构建钩子仍能写同一产物时，先转到唯一入口或退役，避免覆盖新 Prefab。候选到齐后经既有采用入口按来源/目标映射接入，不整库覆盖。原可用成果在新候选完整接入前保留。

完整静态界面达到有据可用状态后，再将现有 Presenter/接口/服务命令绑定到原生完整组件。原奖励槽、排行行、卡片等可由运行时数据动态生成；用户明确的业务规则改变也不授权自由改 UI，必要差异最小化并单列。对象通过序列化引用接线，不把源 ID/节点路径变成 Player 运行时解释器。

四类结果分别记录：纯转换静态恢复、工程采用与保存重开、同版本画面/屏幕适配/正常输入、现有业务接线。构建成功或无 Missing Script 不能替代视觉对照。业务代码和契约未变的已通过结果直接引用；只复验改动影响的 UI、资源和绑定，新绑定确实影响状态/命令时只验受影响路径，不重新练号或全链重跑，测试数据按[运行验收](../../grea/references/测试与结果交付.md#运行验收)。共享 Editor/桌面按实际资源所有者与用户优先规则操作；离线恢复不等待无依赖的打包或其他产品开发。

结束须有整批转换与采用身份、通用缺陷的公开入口消除证据、完整静态界面和实际 UI 对照、正常业务接线，以及替代作者不再覆盖成果。工具和项目各自更新既有[权威任务源](../../grea/references/开发计划与进度管理.md#权威任务源与派生记录)，不新建按页竞争台账；总体验收由本次指定负责人完成。工具或规范修正后按[规则与版本分发](../../grea/references/固定候选与运行连续性.md#规则与版本分发)核实际消费入口。
