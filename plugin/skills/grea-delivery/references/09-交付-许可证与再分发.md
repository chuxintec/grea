# 交付 · 许可证与再分发

> **何时读**：新装第三方包、把源引擎的算法或资源带入 Unity 工程、准备对外交付构建或公开源码、或审计已有工程的许可证风险时。
> **读完产出**：项目第三方组件登记表、源引擎代码与许可证文件头扫描结果、原游戏素材的使用范围说明，以及交付说明中的许可证一节。

本页管三类内容的边界：源引擎运行时代码、原游戏素材、第三方包。授权范围以当前会话和项目 AGENTS 为准；本页不授予任何再分发权利，只规定如何核对和记录。

## 1. 源引擎运行时代码

**规则**：交付的生产工程（`Assets/` 中的运行程序集、Prefab、场景和资源）不包含 Cocos Creator、LayaAir、Egret 等源引擎的运行时源码，也不包含带这些引擎许可证文件头的文件。这条同时是 [原生转换规范](../../grea-native-port/references/05-Unity-原生转换规范.md#禁止项与守卫) 的第 7 项禁止项。

需要原版的某个行为（缓动曲线、布局结果、粒子参数）时，按以下顺序选择实现：

1. **Unity 或选型插件的同名能力**：例如原版 `backOut` 缓动用补间插件自带的 OutBack 曲线，再用关键帧对照确认结果。
2. **烘焙为数据**：用转换器在工程外对原曲线采样，生成 `AnimationCurve` 或 AnimationClip；转换器与采样脚本留在项目 `Tools/`，生产工程只保存生成的原生资产。
3. **独立实现公开公式**：依据公开数学定义自行编写，文件中注明公式来源；对照结果与原版一致即可。

**检查**：守卫扫描源引擎许可证文件头和版权行（如引擎厂商名、`Cocos Creator`、`LayaAir`、`Egret` 版权声明），以及源引擎 API 名称。扫描范围、命中项和处理结论记录在项目验收中。

## 2. 原游戏素材

- **归属**：原游戏的图片、音频、动画、文本和配置属于原权利人。从包中提取不改变归属。
- **默认范围**：在用户授权的工作区内用于取证、恢复和本地验收。对外分发包含原素材的构建、公开原素材或把它们放进公共仓库，都需要用户明确授权，并由用户确认已获得权利人许可。
- **公共内容**：grea 的公共模板、示例、测试夹具和文档只使用合成数据、自有图形或已明确可分发的资源。
- **记录**：项目验收和交付说明写明构建中原素材的来源（包版本、提取方式）和本次交付的分发范围。

## 3. 第三方包

新装或升级任何 Unity 包、插件、Asset Store 资源或开源库时，在项目 `Docs/` 的第三方登记表中记录：

| 字段 | 内容 |
| --- | --- |
| 名称与版本 | 精确版本或提交；来源（UPM、Git、Asset Store、手动导入） |
| 许可证 | 许可证名称与文件位置；无法确认时写"待核对"并阻止对外发布 |
| 分发约束 | 能否随构建分发、能否随源码分发、是否要求署名或附带许可证文本 |
| 使用前提 | 是否要求使用者另持授权（例如 Spine 运行时要求使用者持有 Spine 编辑器许可） |
| 平台验证 | IL2CPP/AOT 与目标平台是否已验证 |
| 备份 | 按工作区约定备份的位置、哈希与恢复方法 |

- Asset Store 资源按其 EULA 处理：随游戏构建使用，不随公开源码仓库分发其源文件。
- 同一能力只登记一种实现（见 [技术选型基线](../../grea-native-port/references/05-Unity-原生转换规范.md#技术选型基线)）；替换后删除旧包并更新登记。
- 包许可证要求在产品中附带声明时，把声明放进构建（例如 About 页或随包的 `THIRD-PARTY-NOTICES`）。

## 4. 流程

1. **盘点**：列出 `Packages/manifest.json`、`Assets/Plugins`、`Assets/ThirdParty` 和嵌入包，补齐登记表。
2. **扫描**：运行守卫中的源引擎代码与许可证文件头扫描；命中项按第 1 节替换。
3. **发布前核对**：确认登记表没有"待核对"项，本次分发范围与原素材授权一致，需要的声明已进入构建。
4. **交付说明**：在 [构建与发布](09-交付-游戏构建与版本发布.md) 的交付说明中写出许可证一节：第三方组件清单链接、原素材来源与分发范围、扫描结果。

## 5. 完成条件

- 登记表覆盖工程中的全部第三方组件，没有"待核对"项（或本次不对外发布，并写明原因）。
- 源引擎代码与许可证文件头扫描零命中，结果计入 [原生可维护门](../../../shared/08-验收-测试与结果交付.md#原生可维护性跨引擎转换)。
- 交付说明写明原素材来源和分发范围，与用户授权一致。
