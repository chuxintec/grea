# 生命周期与变更合同

阶段与模式按任务选择，不要求走完整生命周期。`plan_workflow`、`init_case` 和 `start_case_revision` 接受阶段、模式与交付层级；支持范围及默认值以当前 GREA 契约为准。来源引擎不决定目标引擎。规划结果、合同字段和 `design.state=approved` 都是调用者声明，不授予实现、迁移、发布或生产写入权限。

## 选择模式

| 模式 | 比较基线 | 本期需要明确 |
| --- | --- | --- |
| faithful | 已固定的原版行为、规则、随机、结算和存档语义 | 只修复有依据的差异；不得把推测或新设计写成原版事实。 |
| reskin | 当前工程与用户批准的美术设计 | 替换获批表现，按合同保持布局、入口、操作、规则与持久化语义。换皮制作阶段见[游戏换皮与资源制作](游戏换皮与资源制作.md)。 |
| feature | 旧版本的不变量与批准的新增行为 | 定义可观察目标、允许变化、保留语义及配置/存档/协议/pending 的兼容要求。 |
| tuning | 可比测量基线与明确的目标指标 | 固定 workload、设备、平台、视口、画质、seed、输入和测量口径；列出允许变化，不能把主观偏好当作已证收益。 |
| prototype | 隔离的工程与存档 | 只回答一个明确问题，给出可观察的保留/丢弃条件；候选不是正式玩法或玩家档迁移。 |
| operate | 用户授权可读的数据与输出范围 | 先读后给本地候选；不默认发奖、扣款、公告、修改线上配置或连接发行渠道。 |

## v1 UI/UE 兼容

旧 `evolve/ui_ux` 合同继续接受，仅允许合同明确的视觉、布局、导航、可读性和反馈变化；玩法规则、进度、命中/伤害、随机、费用/奖励、持久化及动画事件/取消语义保持不变。不适用机制不因规范新增。新玩法目标使用相应v2模式，不能借旧UI/UE名称扩大范围。

合同绑定文件SHA，不代表整个源码集合；实际产品/存档身份仍需工程与运行回读。候选设计可作样板，不能标批准设计。验收只覆盖受影响入口、保留旧待验项；未变化证据按身份与范围复用。字段与允许值见[change-contract Schema](../assets/change-contract.schema.json)。

## v2 合同与身份

按所选模式填写 `scope`、基线文件 SHA-256、源/目标产品与存档身份、设计文件及摘要、`objective`、`user_source`、`allowed_changes`、`invariants`、`verification` 和 `compatibility`。合同必须绑定实际基线文件；单个文件的摘要不是整个源码集合的指纹。feature/tuning 在明确兼容合同下可继续同一产品身份；reskin/prototype 必须使用与来源不同的产品和存档身份。身份声明仍需在运行前由工程实际回读确认。

feature 说明新增玩家行为与旧不变量；tuning 说明指标、测量条件和允许改变的维度；prototype 说明实验问题和留弃判据。恢复模式保持 faithful；类型、食谱或常见设计模式都不能单独证明原版存在相应玩法，也不能成为新增“必备玩法”的依据。获批增量按合同实施；未批准的目标只形成方案。

## 配置、存档与协议兼容

将配置内容摘要、存档 Schema 版本、客户端协议版本、服务端数据库版本及 pending 命令身份分别管理。配置 hash 变化本身不能让所有旧档失效；字段增删、类型、单位、枚举、ID 和默认值须有业务依据。未知新档版本应拒绝写入或进入明确的兼容处理，保留旧档、pending 与幂等回执。客户端备份不能覆盖已确认的服务端资产，服务端事实由其所有者按事务和权威读回处理。

`compatibility_plan` 只比较合同声明的顶层字段、类型、显式默认值及 config/save/protocol/pending 差异，并写出新目录候选；它不推断单位或嵌套业务语义，也不执行迁移或 SQL。分析通过不等于旧档兼容；实际迁移需在隔离副本中验证备份、中断恢复和关闭重开。只读事件、经济流与配置预览的输入范围和统计限制见[版本兼容与运营预览工具](版本兼容与运营预览工具.md)。

## 执行与验收

Case/Revision 必须绑定与模式相符的合同、基线和必需验收维度。合同校验只能确认声明及其引用结构，不批准设计、不执行存档迁移、不证明运行结果。按受影响入口验收：旧不变量与新行为分别记录，配置/协议/存档边界单列；prototype 结果继续标为候选。构建、静态检查或合成样本都不等于可玩或全平台通过。仅运行及交付范围另按 [grea-release](../../grea-release/SKILL.md) 处理。
