# 实际体验与画面对照

调研、复刻/移植及开发验证在当前授权范围内必须执行：实际操作→理解机制→截图/连续录像→分析或修正→实际回看。静态解析、菜单截图、构建和工具成功不能替代玩法体验。局部修复只覆盖受影响流程，不因此唤醒归档项目或反复全量录像。

## 调研与原版取证

- 核对游戏/版本或缓存身份、进度、运行环境；体验能解释核心决策的代表循环：进入/准备→操作与选择→结束→结算/收益→成长或再玩。一次失败仅覆盖失败分支，不能以机械时长或一局关闭未理解机制。
- 按顺序体验教学，记录动作、反馈、推进条件与转正式玩法节点。无合法重看入口时引用有效完整录像或保留缺口，不清档/重置冒充新体验。
- 核心培养系统逐类截图：入口、对象/属性、材料来源、成本/条件、效果与主玩法关系。已解锁实际进入；授权内可用正常免费资源体验并留前后状态。待解锁保留锁定状态和条件，不用配置表冒充体验。
- 核心玩法、教学、培养反馈等动态流程保留从操作前至反馈/结算/恢复可操作的连续录像；分段注明衔接与时间码。只点击菜单的旧L1报告保持部分覆盖，不能标完整实玩。

## 开发与UI对照

每组问题提供同页面、状态和版本可比的原版→修前候选→修后候选。布局/文本/错图留截图，输入/跳转/动画/结算留短录像；在真实Editor/Game View或浏览器入口操作，直接调用回调不等于输入验证。多客户端分别给结果，不能互替关闭。

记录内容区、设计尺寸、比例、账号/进度差异；原图原片保留，裁切标注另存。明显错图、缺字乱码、拉伸、遮挡和错误引导/输入错位纳入相应首版修复；精细打磨按批准范围。有效同版本证据复用，小改检查实际影响，成组集成集中确认。

## 单一覆盖记录与核验

在研究或产品既有证据目录维护一份覆盖/差异记录：系统、入口/条件、动作、结果、版本/进度/视口、操作者、截图/视频时间码、状态、下一步。状态区分已实玩、仅观察、部分、待解锁、阻塞、仅静态和未运行。用户操作视频可记观察，不能宣称Agent输入成功。

实际打开图片、解码录像并回看关键动作和结果，确认目标、时长、尺寸和声音情况；文件存在或SHA正确只证明字节。工具不能自动认证理解玩法。账号、原始媒体和素材留项目，不入GREA分发包。

桌面同时只归一个明确操作者，按实际交接记录目标、释放与可恢复位置；未确认释放不能凭时间或隔离目录抢占。输入失败先核窗口/尺寸/坐标链，有限因果修正，披露阻塞并继续独立工作。截图/录屏依当前授权，限制目标内容、不默认麦克风，不扩展付费、广告、账号切换、清档、注入、外发或安装权限。
