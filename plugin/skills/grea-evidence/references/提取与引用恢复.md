# 资源 · 提取与引用恢复

工具推荐：AssetRipper/UnityPy提取，Cpp2IL/ILSpy/Ghidra查逻辑，unity_dependency_audit检查引用，audit_numeric_texture检查数值纹理。 入口和限制见 [工具清单](shared/工具选择与调用.md)。

用于 Unity 原工程恢复及其他源引擎向 Unity 的资产接入；旧网页适配只作为来源证据，不默认开展新网页项目。优先复用项目已验证工具，不因可用工具多而重复扫描整个包。

## 全量提取基线与分类输出

本页只管理提取、原对象身份和数据保真；导入/代码接入见 [工程重建](shared/Unity工程重建与恢复.md)，运行显示见 [界面](shared/Unity界面还原与输入交互.md) 和 [特效](shared/Unity动画特效与事件时序.md)。

完整恢复的首次提取尽可能全面盘点包体内可访问内容并分类导出；后续按包哈希、工具版本、参数和未决依赖增量重跑，不重复覆盖原始输出。全面盘点/提取不等于无目标地人工反编译所有方法。

优先沿用项目目录；无既有结构时使用 `Analysis/extraction/<run-id>/`，下设 `prefabs-scenes/`、`textures-sprites/`、`spine/`、`audio/`、`shaders-materials/`、`models-meshes/`、`animations/`、`configs-fonts/`、`native-libs/`、`managed-code/`、`il2cpp/`。一个可导入 Unity 导出工程可以单独保留，不为分类破坏 GUID/目录引用；分类索引可指向该工程文件。

- Prefab/场景导出对象树、序列化字段、MonoScript 与组件关系；Sprite 保留图集页、rect、UV/网格、旋转、pivot、PPU 和 border。
- Spine 保留 skeleton、atlas、全部页纹理、材质、版本、动画引用与运行时缩放；音频保留原编码和可播放副本及触发映射。
- Shader/材质保留原始数据、可恢复源码/变体、纹理槽、关键字、混合/深度/stencil/队列；占位 Shader 明确标记，不能计为恢复成功。
- 3D 模型保留网格、法线/UV、骨骼、蒙皮、材质、贴图及动画；配置和字体连同关联数据一起索引。
- 原样保留各 ABI 的 SO、托管程序集及 IL2CPP metadata。为 IL2CPP 输出类型、字段、方法地址、签名、交叉引用和按模块恢复的代码；DummyDLL 仅属类型空壳，伪 C 不是完整可编译 C# 工程。

每轮清单记录源包哈希、工具/版本/命令参数、对象身份、输出路径/哈希、依赖和恢复状态。各类别分别统计已发现、已提取、可解析、引用完整、运行已验证、失败/缺失；未发现类别也写明检查范围。输出错误日志、未解析引用及下一轮待办，不能以文件数宣称全部解出。

重跑输出新 run-id，比较新增/变化/失败项及引用修复；确认后更新当前索引，保留旧证据。原始导出只读使用，Unity 工程内的兼容修复放工作副本，并记录替代映射。

## 定位界面与 prefab

1. 确认包版本、Unity 版本、资源包清单和目标界面所处状态。检查现有导出索引。
2. 从界面类、组件字段、对象名称或已知资源进入，定位 GameObject/prefab 及脚本引用。打包后不一定存在独立 `.prefab` 文件。
3. 沿 PPtr 的文件引用和 pathID 解析依赖；记录源包和序列化文件，避免跨包 ID 混淆。
4. 导出对象树及实际组件属性，而不只导出一批名称相似的 PNG。模糊名称或图集候选只能辅助搜索，不能证明某图属于该界面。

## 类型树与对象身份的校验

- MonoBehaviour 只有基础字段或读取失败时，先区分类型树缺失与资源缺失。可用匹配版本的程序集/IL2CPP 元数据补组件 schema，并加载承载外部 MonoScript 的依赖文件；一个导出器读不出字段，不证明原包没有该组件。
- 补 schema 后同时核验字节完整消费、基础头字段、脚本类型及 PPtr 目标。能读完全部字节仍可能存在对齐错误；异常 fileID、无法解释的 pathID 或字段类型应回查原始头和依赖。关闭严格读取仅可辅助定位，不能作为完整恢复的证明。
- 对象身份包含包、序列化文件和 pathID；PPtr 的 fileID 相对所属文件解析。面向 JavaScript 的清单将 64 位 pathID 写为字符串，在 JSON 解析前保住精度。
- 运行时资源名或路径应优先取实际 getter/加载调用结果。单个路径未命中，只排除该路径，不能据此宣布整个界面资源缺失。保留精确来源和文件校验值，避免把公共内容包、默认主题包、编辑页或另一功能分支混为一体。
