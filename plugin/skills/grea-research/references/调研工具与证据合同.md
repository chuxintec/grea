# 调研归一工具与证据合同

本参考说明 `research_report` 的输入、归一和输出边界。调研判断方法与报告结构见同目录的[游戏调研与成本判断](游戏调研与成本判断.md)。当前源码已登记该工具并提供输入校验与报告生成；实际安装能力仍以当前CLI/MCP为准，不把源码存在当作插件已更新。

## 调用

从已安装的 GREA 根目录调用统一执行层；以当前安装的 `list-tools` 与 `describe-tool` 结果核实能力和参数，不依赖源码树路径：

```sh
grea describe-tool '{"tool_id":"research_report"}'
grea run-tool '{"tool_id":"research_report","arguments":["--input","/absolute/evidence.json","--output","/absolute/new-report"],"run_dir":"/absolute/new-run"}'
```

旧 CLI 兼容形式为 `grea legacy research_report --input evidence.json --output new-report`；MCP 与 CLI 共用执行层。输出目录必须是新目录，输入及显式证据只读。工具生成 `research.json` 与 `report.md`。

## 输入归一

- 输入 JSON 最大 8 MiB；显式来源文件合计最多 64 MiB。来源路径相对输入文件解析，禁止越界路径和符号链接；SHA-256 不匹配时拒绝处理。
- `sources` 声明实际证据文件；`items` 用稳定 ID、`kind`、`stage`、`source_id` 分类；`protocols` 用 `name`、`direction`、`kind` 区分 `rpc`、`message`、`field`。
- 只将 `kind=rpc` 的条目统计为 RPC，嵌套字段不计 RPC，配置行不计玩法数量。输出按实际提供的分类去重；没有材料支持的指标为 `null`。`complete_kinds` 只是调用者声明覆盖完整的类别，不是工具认证。
- `judgments` 显式记录事实、推断、假设、经验或未知及来源。`estimates` 记录工种、主动人工小时区间、协作工作日区间、是否包含后端、前提和置信度；不自动估价，不内置 AI 倍率。共享后端与配置不得在双客户端重复计成本。
- 来源文件校验只证明所列字节与 SHA 相符，不证明分类判断正确；工具不解包游戏、不自动分析私有协议，也不认证结论。

## 实玩覆盖

可选 `play_coverage` 按 `core_loop`、`tutorial`、`progression`、`ui_comparison` 分别记录 `system/status`、`identity`（版本、进度、视口）、`operator`、`entry/actions/result/understanding/next_step` 与媒体。状态可为 `played`、`observed`、`partial`、`locked`、`blocked`、`static_only`、`not_run`、`not_applicable`。媒体关联 `sources`，类型为 screenshot 或 video，视频应记录实际回看时间码。

`played` 仅为分析者申报：工具核对来源 SHA、关联、媒体类型和视频时间码，不解码媒体，也不认证机制理解。循环与教学申报 played 需视频，培养与画面对照需截图；动态培养或交互仍需录像。旧输入不含该字段时保持兼容，输出标为 `not_provided` 并保留实玩缺口。未覆盖系统逐项列明，不能用四类各一行代替全系统覆盖；不存在的培养系统或暂无候选 UI 对照可填 `not_applicable`，并说明依据。

## 输出解释

`declared`、`acquired`、`parsed`、`reference_closed`、`runtime` 是不同阶段，不能互相推导。按阶段分别去重。Prefab、EUI、Spine 版本、角色、关卡、配置行与玩法系统分开统计。`parsed` 不代表实际运行，运行资源计数不代表完整实玩。结论应说明来源和置信度；工具退出成功仅表示当前声明范围处理完成，不代表原生引擎、玩法或市场判断通过。

## 输入结构

生成的 [research-input Schema](../assets/research-input.schema.json) 随技能分发，字段、枚举与必填项以它为准；与 GREA 运行时同源生成。最小结构如下，空 sources/items 只演示形状，不构成调研证据：

```json
{"schema_version":1,"game":"自有样本","sources":[],"items":[],"protocols":[]}
```

真实输入按 Schema 加入已取得且逐份核验的来源和分类；无来源的结论维持未知。运行时若拒绝此合同，先核实际 GREA 版本，不自行删除校验或猜测字段。
