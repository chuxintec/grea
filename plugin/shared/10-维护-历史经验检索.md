# 维护 · 历史经验检索

仅在需要解释旧返工或寻找可复用经验时读取。当前执行规则由 SKILL 与主题参考维护；项目现状查项目最新验收，历史记录不自动成为当前事实。

- [工作区记忆索引（外部历史资料）](../../docs/维护与发布.md)：按玩法、资源、输入、架构、验收和素材主题选读，不全量加载。
- [历史案例来源（外部历史资料）](../../docs/维护与发布.md)：原参考中的项目来源、失败案例及当时未验收边界。
- [复盘与规则晋升](10-维护-开发复盘与规范更新.md)：核对证据后决定修规范、留经验或保持项目专用。

projects 内的原始证据未必随根 Git 分发。缺少来源时注明未现场复核，不能因此猜项目当前状态，也不阻止与该历史材料无依赖的工作。
