# 双客户端与共享服务的可选五岗协作

仅对已获并行授权、确有双客户端与共享后端工作的项目使用；单开发者、模型和人数服从当前用户要求，不默认启动五Agent。

主开发者负责集成、唯一任务表和桌面交接；按就绪工作动态启用0～5岗位：Unity客户端、Cocos客户端、Go服务器、Unity Resource、Cocos Resource。纯UI不新派后端；资源岗可共用原版证据，各客户端分别交候选与运行结果。岗位名不代表实际已执行。

每个成组工作包一次给齐用户可见成果、基线、准确工具入口/参数、资源名或UUID、原版截图/录像及时间码、布局文字依据、文件单写范围、输出和必要检查。缺原图时明确资源岗补证，不让客户端反复猜图。主开发不与岗位同写同文件，完成包及时集成；两端就绪的UI修正可独立推进，不全部串在主开发长流程之后。

同岗优先复用现有实例；仅阻塞、接口变化、资源交接和成组成果时通信，无普通ACK循环。真实团队记录包含实例、包、文件范围和状态；桌面同一时刻明确一个owner，释放后交回可恢复位置，用户接管优先。离线岗位继续代码/资源工作，不凭不同App并行控制鼠标。

交付原版/修前/修后对照及实际运行身份；代码提交、离线报告和角色名册都不能代替可操作结果。此参考不指定用户本机目录，不改变项目提交、部署、安装或发布权限。
