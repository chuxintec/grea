# CLI 与 MCP 使用手册

CLI 使用 JSON 参数，MCP 使用结构化参数；两者共用操作合同。先调用 `session`，再用 `list-tools` 和 `describe-tool` 查询实际能力。

## 操作

<!-- operations:start -->
| CLI / MCP 操作 | 契约描述 |
| --- | --- |
| `session` / `session` | Inspect grea identity, catalog digest and readiness without launching providers; optionally check an installed Skill. |
| `list-tools` / `list_tools` | List the complete registered provider/helper inventory, including unavailable entries. |
| `describe-tool` / `describe_tool` | Read one registered tool contract, effects, command and limitations. |
| `doctor` / `doctor` | Inspect installation presence; only run explicit selected version/help probes when probe=true. |
| `inspect-target` / `inspect_target` | Inventory a supplied artifact with content digests and explicit partial coverage; never execute it. |
| `plan-workflow` / `plan_workflow` | Select source/target-specific research, client or Go backend steps, dimensions and references; does not execute the plan. |
| `run-tool` / `run_tool` | Run one exact registered command with explicit argv and a new log directory; preserve nonzero/timeout/partial outcomes. Does not grant approval or assert game parity. |
| `init-case` / `init_case` | Create a project-local immutable baseline and explicit required acceptance dimensions. Existing cases are not overwritten. |
| `add-evidence` / `add_evidence` | Register an existing evidence file and its source/candidate role with a verified digest. The role is caller-declared, not authenticated original gameplay. |
| `record-verification` / `record_verification` | Record an explicit reviewer verdict for one dimension, bound to existing evidence IDs. It records a claim; it does not run tests or inspect images. |
| `case-status` / `case_status` | Recheck source/evidence integrity and report declared verdicts, missing coverage and contradictions. Static evidence cannot substitute for runtime/visual proof. |
| `start-case-revision` / `start_case_revision` | Freeze an explicit candidate selection and optional build identity as a new immutable revision; preserves old records. |
| `audit-unity-dependencies` / `audit_unity_dependencies` | Audit a Unity Assets text-GUID dependency closure from explicit root assets. Dynamic references still require Editor verification. |
| `snapshot-unity-assets` / `snapshot_unity_assets` | Snapshot Unity asset paths, GUIDs, contents and Resources keys without moving assets or modifying Unity. |
| `compare-gameplay-traces` / `compare_gameplay_traces` | Find the first divergence between two ordered gameplay JSONL traces at explicit JSON Pointer fields. Does not establish correct sampling or reorder concurrent events. |
| `inspect-numeric-texture` / `inspect_numeric_texture` | Validate raw floating-point texture bytes (VAT/numeric maps); ordinary PNG imagery is not equivalent numeric evidence. |
| `validate-unity-project` / `validate_unity_project` | Read-only profile/path/dependency/assembly checks. No Unity launch, writes or runtime acceptance. |
| `plan-unity-project` / `plan_unity_project` | Create a deterministic design-only Unity plan on stdout. No generation or project writes; generationReady is always false for this read-only operation. |
| `plan-unity-generation` / `plan_unity_generation` | Plan create-only recipe or read-only adopt. No Unity process or writes. |
| `generate-unity-project` / `generate_unity_project` | Generate a new staged Unity project with Editor-created prefabs, verify and publish. Existing owned projects are verified without overwrites. |
| `recover-unity-generation` / `recover_unity_generation` | Resume a specific interrupted generation run after identity checks. Conflicts are retained; no automatic deletion or overwrite. |
<!-- operations:end -->

## 调用与结果

```sh
grea session
grea describe-tool '{"tool_id":"unity_player_audit"}'
```

执行预算、原始退出码、截断、Case/revision 记录及验收层的权威说明见 [接口调用与证据记录](../plugin/skills/grea/references/接口调用与证据记录.md)。安装见[安装与平台](安装与平台.md)，日常入口见[使用指南](使用指南.md)。

操作表由 `contracts.catalog()` 生成，维护时运行 `python3 scripts/check_docs.py --write-catalog`，CI 检查漂移。
