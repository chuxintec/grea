# 可分发内容与脱敏规范

产品只维护通用功能、公开依赖来源与可复查的匿名测试摘要。真实业务项目、用户身份和机器环境信息不作为分发内容。

## 保留与排除

- 保留工具 ID、参数契约、功能规则、公开上游版本／许可证与通用夹具。第三方二进制、vendor 源码、实际包备份和项目派生适配器只在本机保留，不随公开 Git 分发。
- 路径使用仓库相对位置、用户显式输入或运行时发现；示例使用占位目录，不写某位操作者的用户名或安装目录。
- 玩法与资源规则描述适用条件，不保存具体游戏名、项目编号、关卡参数、截图文件名或项目专用修复脚本。
- 原始日志、迁移清单、业务验收记录与专用插件保留在仓库外。公开摘要必须区分实际测试与未执行项，不伪造原始证据。
- 本地运行时、配置、缓存与 Git 元数据不属于分发扫描范围。上游原版二进制可能保留供应方 CI 编译路径；不为清理供应方信息破坏签名或篡改许可证。

## 包备份

通用包备份仅记录匿名来源编号及工程内相对位置。归档的 uid、gid、uname、gname 和时间元数据归一化，包内文件保持原字节。重新打包后必须更新所有归档 SHA-256 与大小字段，并确认安装计划仍能验证当前清单。

新输入可能自带业务内容或敏感文本，元数据归一化不代替包内内容审查。项目资源包与来源不明的私人插件不应放入通用库存。

## 验证与 Git 边界

检查当前待分发文件名、文本、必要的二进制字符串及压缩包成员；回归受影响入口、归档恢复和文档链接。测试日志在外部保存，仓库仅记录不包含环境身份的结果摘要。

工作树脱敏不会清除旧提交、远端副本或已下载克隆。提交／推送与历史重写分别处理；没有明确历史清理授权时，不强推改写仓库历史。历史原始资料移出产品后，不再作为当前公开测试证据。

## 暂存区发布门槛

运行 `python3 scripts/audit_public_tree.py` 检查将被提交的实际字节：本机路径、项目标识、典型访问令牌、私钥、带凭据 URL、私网地址、二进制、LFS 指针及受限目录。工具只返回位置和类别，不输出匹配值；它不替代人工隐私与许可审阅，也不保证不存在所有种类的秘密。

GitHub CI 对每次提交和 PR 运行同一检查。依赖许可与安装边界见 [第三方说明](../THIRD_PARTY.md)，贡献要求见 [贡献指南](../CONTRIBUTING.md)。
