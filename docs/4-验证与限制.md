# 验证与限制

验证采用通用输入夹具，原始业务日志和本机路径不随产品分发。需要复验时按 [维护说明](6-维护说明.md) 执行当前版本测试，不把历史测试次数当作本次结果。

## 验证层级

- 输入契约、错误分支与受控执行：检查 CLI／MCP 一致性、日志预算、超时和取消。
- 资源及规则工具：检查有效输入、差异、损坏数据、输出冲突及符号链接边界。
- 证据记录：核对来源角色、文件身份、变化与缺口；审阅声明不自动证明游戏等价。
- 平台：模拟路由不能代替目标系统原生执行；第三方工具还需真实样本验证。
- 文档：检查本地链接、锚点和 JSON 示例，不能替代 Agent 行为评估。

## 发布记录

对外摘要只记录版本、测试项、结果与未验证范围。调用者目录、用户名、设备标识、原始输入和业务案例保留在外部项目；涉及来源身份的摘要标明已脱敏，不能充当原始取证日志。

运行预算不包含硬性 RSS 上限；所属进程组清理不覆盖脱离组的守护进程。Windows 文件锁与进程清理限制见 [平台说明](5-工具整合与跨平台.md#平台结论)。
