# Cocos Creator 目标工具接入手册

`cocos_project` 与 `cocos_convert` 是开发候选。先用 GREA `list-tools` / `describe-tool` 核实安装版本和支持范围，再以 `run-tool` 调用，并选择全新的输出目录。生成或转换后仍需在目标 Creator 版本中导入、编译并做浏览器/目标渠道验证。
