# Native runtime presentation update

`upgrade-native-runtime --candidate <frozen-selection> --expected-manifest <sha256> --out <new-directory>` copies a clean saved selection and replaces only exact recognized producer templates. It preserves existing Prefab, resource and metadata bytes, gives new helpers deterministic GUIDs, and updates the producer-declared compile dependency graph. An unknown or consumer-edited helper is rejected. The result is a new candidate; native compilation and consumer validation remain required.

The runtime presentation path uses ordinary native `Image`, `RawImage` and `TextMeshProUGUI` components as sources. During Play mode it rebuilds the sources through their native APIs and projects current geometry, material/texture, vertex colors, CanvasRenderer tint, inherited alpha and visibility into separately owned runtime meshes. Existing queue positions and stencil hierarchy stay in place. New TMP material slots receive transient proxies. Persisted static mesh assets are never modified. Edit-mode static snapshots retain their original verification role.

Input uses a supplemental GraphicRaycaster only when its Canvas has exactly one enabled authored GraphicRaycaster. It preserves that component's current blocking policy, tests original source rectangles and ancestor filters, and returns the original source GameObject to EventSystem. It does not dispatch or simulate events. A retained Button whose transition target is a sibling and whose hit node has no Graphic receives a transparent runtime input surface. The retained target exposes `Monkey.NativeUiContracts.INativeStaticButtonTarget`; consumers may namespace their helper class without changing that interface. The project still enables and wires the actual Button. Disabled/interactable behavior remains native Selectable behavior.

A proxy disabled in the saved consumer Prefab is an explicit initial opt-out and is not automatically reenabled. This permits a temporary live-control adapter to coexist during migration. Once the consumer has validated the generic path it can retire that adapter deliberately; copying new helper files is not evidence that the adapter was retired. Presenter/Canvas disable and reenable clean up owned transient state and retain source rendering/input ownership.

This profile does not lower dynamic Spine behavior, animation curves, arbitrary material-modifier scripts, new source objects, source queue reordering or changing internal mask geometry. Those require their own native evidence or a new plan. Existing source-empty/disabled conditions remain explicit; ordinary source-component enablement is not fabricated by the presenter. Actual pointer/device input and product business behavior remain separate from neutral EventSystem raycast/callback probes.
