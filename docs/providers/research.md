# 调研报告工具接入手册

`research_report` 是开发候选，旧插件继续可用。通过 GREA 安装入口的 `list-tools` / `describe-tool` 确认能力，再用 `run-tool` 传入 `--input`、`--output` 与新 `run_dir`。

数据字段、预算、实玩证据和结果边界以已安装的 Skill reference [调研工具与证据合同](../../plugin/skills/grea-research/references/调研工具与证据合同.md) 为准；总体判断方法见对应 Skill 的[游戏调研与成本判断](../../plugin/skills/grea-research/references/游戏调研与成本判断.md)。
