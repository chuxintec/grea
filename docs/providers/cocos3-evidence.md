# Creator 3.4.1 / CCON 接入手册

先以包体或项目证据确认 Creator 版本，再通过 GREA 的 `list-tools` / `describe-tool` 确认 `cocos_assets`、`cocos_modules` 当前能力；调用时明确 adapter、来源和全新输出目录。不要按 header 单独推断 Creator 版本，也不要执行工厂函数。

索引 bundle、CCON JSON/BIN 和 System.register 的有限格式范围及证据边界迁至 Skill reference [Creator 序列化与 CCON 证据](../../plugin/skills/grea-recover/references/Creator序列化与CCON证据.md)。
