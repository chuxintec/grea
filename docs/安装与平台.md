# 安装与平台

用途：在本机安装 grea，确认技能、MCP 与工具各自能否使用。包版本以 `plugin/version.json` 为准；历史报告不代表本机能力。

## 选择分发包

| 包 | 内容与前提 |
| --- | --- |
| 完整 macos-arm64 插件 | 自带 Python、锁定依赖、8 个技能、本地 stdio MCP；原生 Apple Silicon |
| 完整 windows-x64 插件 | 自带原生 python.exe 与相同业务实现；Windows Server 原生 CI 验收；Windows 11 桌面/Unity/Player 实机未验 |
| Git / GitHub 自动源码下载 | 开发与维护，需要 uv；不含私有依赖或 Python 二进制 |

使用官方 Release 附件并核对 `SHA256SUMS` 与 manifest 的 target/source revision；功能分支 CI 制品不视为正式版。Windows ARM64、macOS Intel、WSL/Wine 不自动支持。

## 完整插件安装

解压到普通用户可读的稳定目录，不需要系统 Python、uv、Git Bash 或首启下载。Windows 包直接调用 `runtime/python.exe`，不通过 cmd 解释插件路径。保留解压目录作为本地来源。

在解压后的 `grea` 目录，用已安装的原生 Codex 执行：

```text
codex plugin marketplace add .
codex plugin add grea@grea-local
codex plugin list --marketplace grea-local --json
```

重启客户端并开新会话，调用 `session`：版本与 `package_root` 必须指向安装副本。installed/enabled、技能可见、MCP 工具发现和真实工具执行分别检查。独立 stdio 验收不等于真实客户端加载。

Claude Code 清单随包提供；仅在用户要求安装该客户端时执行 `claude plugin marketplace add ./`、`claude plugin install grea@grea-local`。本轮不变更用户 Claude 安装。

## 源码安装

```sh
uv sync --frozen
./bin/grea session
```

Windows PowerShell 使用 `bin\grea.cmd session`；所有平台也可用对应虚拟环境 Python 执行 `launch.py session`。JSON 请求优先放 UTF-8 文件后传 `--input`，避免 Shell 引号差异。

## 可选供应方与支持范围

核心工具不要求安装全部外部软件。Node/Acorn、.NET/Cecil、Unity Editor、AssetRipper、ffmpeg 等按任务准备，配置 `GREA_PROVIDERS` 指向 [供应方示例](../providers.example.json)形状的本地 JSON；只覆盖 canonical ID，声明真实 systems/architectures 和 argv 数组。

`describe-tool` 中 detected/help 成功不是业务通过。逐项声明与原生验收见 [平台矩阵](../schemas/tool-platform-matrix.json)及 [验证索引](../validation/README.md)。Unity、桌面输入、Windows Server CLI 分开验收；未提供对应报告的项均未验证。

## 升级与回退

先保留旧包及校验文件，安装新版本到新目录，核对客户端只启用一个同名 MCP。新会话完成 session 和一次真实工具调用后再移除旧注册。失败时恢复旧插件来源；不覆盖游戏工程、Case 或存档。旧工具 ID/参数继续使用；文件路径变化见 [路径映射](../schemas/document-path-map.json)。
