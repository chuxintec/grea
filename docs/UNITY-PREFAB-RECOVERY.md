# Selected Unity-source Prefab recovery

Development profile: source Unity 2021.3.30f1, target Unity 6000.6.2f1 and uGUI 2.6.0. This additive profile reuses pinned inspection and AssetRipper exports. It does not execute source assemblies, WASM or source business code. Existing commands and fixed artifacts remain unchanged.

## Public commands

```
monkey recover-unity-prefabs --request REQUEST.json --expected-request SHA256 --out NEW_DIRECTORY
monkey verify-unity-prefabs --candidate CANDIDATE/UnityProject --expected-manifest SHA256 --unity-editor EXACT_EDITOR --out NEW_DIRECTORY --budget-seconds 600
monkey verify-unity-prefabs --candidate CANDIDATE/UnityProject --expected-manifest SHA256 --unity-editor EXACT_EDITOR --out NEW_DIRECTORY --headless
monkey freeze-unity-prefabs --native-output NATIVE_DIRECTORY --expected-execution SHA256 --out NEW_DIRECTORY
monkey inspect-unity-prefab-schemas --request REQUEST.json --expected-request SHA256 --out NEW_DIRECTORY
```

Generation returns exit 1 with `needs_action`: generated output is not native acceptance. Verification runs only a fresh owned copy, refuses concurrent main Unity/Creator Editors, pins its plan/helper, retains logs and readback, and stops only its own child when its budget expires. `native-verified-subset` requires readback `completed` and child exit 0. `native-partial` retains explicit unsupported presentation with exit 1. Neither status proves Player, business, visual parity or consumer adoption. A timed-out or failed child is not accepted from counts or an old readback.

`--headless` runs with `-batchmode -nographics`, defers rendering/visible edits and preserves partial status. A second independent headless process verifies the saved state without saving again and compares all native identity/reference tables across processes. Freeze requires both exited processes, exact original/source and readback hashes, and unchanged post-exit file bytes. It excludes Library and the Editor verifier and produces the existing target-profile/namespace/file-ownership manifest for adoption preflight. Source namespace is derived from the complete selected root identities; it does not imply compatibility with an existing consumer assembly or Resources key.

## Request contract

`monkey-unity-prefab-recovery-request/1`, schemaVersion 1, requires the exact target version, source roots `{sourceSha256,file,pathId}`, a pinned input index and a pinned provider export inventory/receipt/binding/prepared-job lineage. Optional source selection and metadata pins remain evidence, never implementation selectors. Type evidence pins DummyDLL bytes and prior static decompiler declarations per assembly. Declarations prove schema only; this command does not rerun the decompiler or recover methods. Explicit `allowDisabledUnavailableCarriers` permits only proven field carriers with disclosed source/target base differences and disabled unavailable behavior.

Optional `sdkEvidence` pins official target C# sources, metadata and their assembly definitions. A source assembly/namespace/class maps only to an exact pinned target declaration and script GUID/localID. Native reconstruction must independently verify GetClass and the actual script tuple. Provider stubs remain quarantined outside Assets; a planned SDK rebind remains pending until native verification. Optional per-assembly `ilDeclarations` pins static IL text for exact declared field assembly/type references, including cross-assembly enums; it does not execute or recover source methods.

Optional `builtinSchemaReceipts` supplies fresh, pinned exact-source built-in schemas. The schema command accepts `monkey-unity-prefab-builtin-schema-request/1` with source, providerPython, wantedObjects and budgetSeconds. It reads at most 32 exact objects through the existing pinned UnityPy worker, recording process exit and unchanged source bytes. New schema evidence does not assert equivalence to an earlier reader. The graph retains source identities and references for all indexed files; typed-value/string budgets apply to reachable objects and used schemas, with separate whole-file alias guards. Serialized external GUID hex is explicitly raw bytes; native GUID text conversion does not infer resource names from path IDs.

The input index binds existing source/inspection/typed-object receipts and a combined serialized-file lookup. Selected originals, selected derived provider inputs, receipts, schemas and payloads are hash checked. Prior reader fingerprints are retained as prior evidence; they are not asserted equal to the current reader. Missing or ambiguous external identities remain gaps. Graph object identities include container SHA, serialized-file SHA/name and path ID. Built-in engine references retain original identity and are unverified until native readback.

Provider selection uses exact original AssetBundle container paths and GUID closure, not first basename matches. Original Prefab/resource/meta bytes are copied unchanged; generated script declarations preserve original assembly and type identity. Runtime layout uses the existing GUID-preserving layout planner. Unsupported code is retained outside Assets; original executable assemblies and provider assembly definitions are not admitted. Unknown methods are never replaced with empty implementations.

## Candidate and native evidence

`UnityProject/manifest.json` owns exact generated files. Source graph, prior input receipts, declaration evidence, provider lineage, schema/carrier dispositions and relocation mappings live under Analysis. The generation report separates native, static and business status. Native expectations derive hierarchy/component order/fields/references from source evidence and target resource GUIDs from retained metadata. Multi-root provider paths join through exact pinned container SHA, serialized filename and path ID; neither request order nor graph order supplies identity. Native readback records actual class/assembly, GUID/localID/type, field storage types, saved/reopened identity and representative text/image/transform edit renders. Source enabled values are checked before unavailable behaviors are explicitly disabled; persisted disabled state is checked afterward.

The first development profile remains acceptance-pending. Compiled source shaders, unsupported source effects, target-native script mapping and non-UI render scope can require further work. Do not infer a complete module, ten-root exit or all-Unity support from generation, local tests or successful SDK compilation alone. Fixed producer/package identities and actual consumer receipts are separate handoff requirements.

Source RectTransform stored Transform XY may be stale relative to anchoredPosition. Native expectations retain those stored source values as evidence and derive actual XY from the source parent size, anchors and pivots; all authoritative Rect fields remain checked. Source UInt8 fields become bool expectations only with proven declaration/native field profiles, including the bounded UI.FontData bool fields. Integers, enum storage and array lengths remain distinct from bool and float fields in actual readback.

## Independently created embedded Sprite resources

`monkey rebuild-unity-prefab-assets --request REQUEST.json --expected-request SHA256 --unity-editor EXACT_EDITOR --out NEW_DIRECTORY` accepts `monkey-unity-prefab-native-assets-request/1`, schemaVersion 1, a `candidate` object with `path` and `manifestSha256`, and 1–64 exact `spriteSourceIds` from its pinned source graph. The source candidate must retain its prepared-hydration/job pins. This bounded profile covers independent local textures, single-mip ASTC8x8 cache evidence and full-texture unpacked-tight Sprites (`settingsRaw=64`). Shared source textures within one selection are rejected explicitly. It does not infer source identity from a name, render-data key or builtin ID.

The tool reuses the source cache decoder and exact hydration hashes, creates new native Texture2D/Sprite assets in an isolated no-graphics project, saves/reloads them and validates them again in a second read-only process. Positions, padding and triangle indices remain exact; the original empty UV cache may populate only the already verified source-derived UVs at the existing 1e-6 tolerance. Source `m_RD.settingsRaw` stays exactly 64. Target-only `m_AtlasRD` cache flags are recorded separately and are not asserted source-equivalent. New textures are explicitly decoded RGBA32, CPU-readable and without mips; original compression/readability and original GUIDs are not claimed preserved. Original object data and hashes remain evidence. Source geometry, pixels, crop, names and sampler settings must verify; neither compilation nor a process exit alone accepts an asset.

The output `Candidate/manifest.json` uses `monkey-unity-prefab-native-assets/1` and owns the actual native files and first/cold receipts. Optional `nativeAssetEvidence` on a recovery request pins these manifests. Recovery verifies both native receipts, current source object/data identity, current original hydration, GUID/meta and complete paired mappings before copying the new native bytes. The ordinary Prefab verifier then binds exact observed native GUID/localID/type through those source identities. Resource reconstruction does not add a recovered root, prove a visible interface or restore source methods.

## Preserved rectangle-atlas Sprite mode

The same native-assets request can explicitly add `atlasPixelManifest: {path, sha256}`, `providerAssetsRoot` equal to the pinned candidate root, and `providerAssets` mapping every selected source Sprite ID to `{assetPath}`. Paths must be the exact candidate relocation targets. The candidate manifest must own the graph, source inputs, relocation report and existing Sprite asset/meta. The planner checks the immutable original bundle, atlas membership, unique render key, exact texture identity and selected original PNG evidence. Render keys and names never supply a native GUID. Trimmed, rotated or differently sized regions are refused.

This mode stages existing native Sprite assets and metadata into a fresh isolated project and creates one native Texture2D per distinct source texture. Shared texture identity requires identical pixels, dimensions, name, path and sampler fields. The selected PNG's documented flip is reversed and its decoded RGBA SHA must equal the pinned original hydration. Sprite GUID/localID/meta, vertices, indices, crop, pivot, border, PPU and source physics outlines must survive texture rebinding, save and a separate read-only reopen. A missing texture's zero public UV cache is not treated as source UV evidence; repaired public UVs must match source float32 multiply/add/divide arithmetic without clamping. Observed missing-texture native cache flags 3139 are distinct from original packed flags 67; repaired main render flags must return to 67, while native atlas cache flags are independently checked and recorded. Unknown bits are refused.

An atlas supplement owns unique Sprite and shared Texture mappings. `replacesProviderAsset` pins its original provider path, original asset/meta SHA, GUID and localID. Recovery may replace only those exact bytes inside its newly generated isolated candidate, before relocation; stale or mismatched bytes fail. It cannot overwrite a development project or bypass missing behavior/visual checks. Old preparation reports remain immutable even when a new exact local pixel selection supplies the missing evidence.

## Selected original Texture2D / Material repair

`rebuild-unity-prefab-texture-material-assets --request REQUEST --expected-request SHA256 --unity-editor EXACT_EDITOR --budget-seconds 600 --out FRESH_OUTPUT` accepts `monkey-unity-prefab-texture-material-request/1`. The request binds an unchanged source candidate manifest, an exact selected-pixel export, distinct source Texture2D/Material IDs and before-pinned provider Material paths. Selected pixels may be complete while the enclosing export stays partial. Only the proven `_MainTex` pointer is rebound through native SerializedObject; source property arrays, sampler, native GUID/localID/type and the existing Shader identity closure are checked. The command creates a fresh isolated no-graphics project and independently reopens its saved assets in a second process. Existing main Editors block execution.

A successful resource supplement is `monkey-unity-prefab-texture-material-assets/1`. It is accepted by `recover-unity-prefabs` only after exact source/data/pixel identities, file hashes, successful independent process readbacks and provider-before identities match. Parent Prefab native save/cold checks and `freeze-unity-prefabs` remain separate. Source compiled Shader semantics, visible rendering, Player/business and version completeness are unverified by this resource repair. Prior partial source inventories and diagnostic evidence are retained rather than silently removed.

The bounded dev7 increment also integrates source-proven unrotated atlas trimming, source-driven Slider anchors, exact Renderer byte/Boolean profiles and float32 RectTransform arithmetic. Unsupported ParticleSystem empty-curve representation remains a strict refusal; no successful parent acceptance is implied by resource repair.
