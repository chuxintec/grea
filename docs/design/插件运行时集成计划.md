# grea 插件运行时集成计划

日期：2026-10-16。范围：当前开发分支，macOS arm64，本地构建与隔离验收，不发布。

**目标：** 安装插件制品后直接启动本地 stdio MCP，无需源码仓库、系统 Python、uv、手工绝对路径或联网安装依赖。

**架构：** `plugin/` 维护技能与两种客户端清单，`src/grea/` 保持唯一业务实现。构建时组装独立 CPython、锁定依赖、产品资源与技能；安装目录只读，输出由调用者明确指定。旧 CLI、工具 ID、MCP 契约不变。

**实现：** Python 3.12 的 python-build-standalone macOS arm64 发行包，固定 URL/SHA256；Python 依赖由 `uv.lock` 导出并校验哈希。依赖与二进制仅进入忽略的缓存和制品，不进入 Git。

## 可执行检查

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_plugin*.py' -v
.venv/bin/python scripts/build_plugin.py --worktree --out dist/plugin-preview
.venv/bin/python scripts/verify_plugin.py --bundle dist/plugin-preview/grea-plugin-macos-arm64.zip --report dist/plugin-preview/acceptance.json
.venv/bin/python scripts/verify_plugin_clients.py --bundle dist/plugin-preview/grea-plugin-macos-arm64.zip --report dist/plugin-preview/native-clients.json
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/generate_contracts.py --check
.venv/bin/python scripts/check_docs.py
python3 scripts/sync_skill.py
python3 scripts/sync_skill.py --check
```

源码快照、第三方下载与验收临时环境保存在忽略目录；不修改游戏原工程，不替换用户全局客户端设置。Unity Editor、商业插件与大型可选外部工具独立检测，其缺失不阻止核心 MCP 启动。macOS arm64 原生结果不扩展为其他平台结论。
