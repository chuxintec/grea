# Unity 框架提炼清单

基线：`v2026.10.16-rc1` / `8521ca5468454da147306a1047ddd5e9d1c0426a`。本次在独立开发分支执行，进度见[执行计划](unity-framework-extraction-20261016.md)。候选源码只读冻结于本次私有运行目录；此处只公布类型契约和所读字节的哈希，不分发来源工程及素材。

## 准入结论

| 能力 | 结论与现有归属 | 输入、输出与所有者 | 失败、取消与验证依据 |
| --- | --- | --- | --- |
| 作用域、代次、租约 | 复用 Foundation `LifetimeScope` / `OperationStamp` / `Lease` | 主线程创建者持有作用域；回调携带代次；子作用域不超越父级 | 先失效再逆序释放；重复释放幂等；不强制结束不合作的 Task；既有 FoundationTests，两个新消费者另验 |
| 服务启动 | 复用 `ServiceScope`，不新建服务定位器或 DI 框架 | 显式构造顺序；Ready/Faulted/Stopped；Bootstrap 装配 | 失败初始化项及已进入项逆序清理，保留启动/清理异常；Stop 等待真实初始化结束 |
| 按钮命令 | 复用 uGUI `CommandButton` 与 Unity `Button` | Button 引用、owner 和命令；只持有监听/防重入状态 | 隐藏取消、重显恢复存活 owner；晚到结果不得更新新代次；Pending 与业务成功分别报告 |
| 有限按压反馈 | 补现有 uGUI 包的实证缺口；候选 C01 | 显式 Button、视觉 Transform、按压比例、时长；只输出局部缩放，不调用业务 | Unity Button Transition 已有颜色/图片/Animator，缺少无需 Animator 资源的有限缩放接入；需验证拖出、拖动、异指针、失焦、禁用、外部基础缩放变化 |
| 页面替换、弹窗 | 复用 `ScreenHost` / `ModalPanel` | 显式内容、遮罩、关闭按钮、首次选择和 EventSystem；owner 管可见期 | 单 host 替换，不假称模态栈；重开、父禁用、销毁、旧代次/焦点恢复分别验证 |
| 资源引用 | 复用 `AssetCatalog` | key→显式 Unity 对象；作用域持有引用声明 | 未找到、类型错、已销毁显式失败；释放引用计数不等于卸载 Unity 内存；不新增资源系统 |
| 音频 | 复用 `AudioPlayer` + Unity AudioSource/AudioMixer | clip、宿主、可选混音组；scope 拥有可停止句柄 | owner 退出停止并清引用；不增加专用音频管理器；示例仅使用自有合成音频 |
| 文件存档 | 复用 Foundation `ISaveStore` / `FileSaveStore`；C02 仅作兼容反例 | 显式独占根、玩家/QA 命名空间、版本化字符串 DTO；Services 编码，Gameplay 定提交点 | 校验失败拒绝覆盖；pending 恢复必须显式决定；两消费者自行保存自己的状态，不采用来源项目文件名/旧档语义 |
| 诊断 | 复用 `DiagnosticBuffer`；示例 QA 另存有界技术事件 | 模块、operationId、短技术标识；owner 定预算 | 不记录账号、完整存档或私有路径；测试数量不作为性能承诺 |
| 布局安全区、宿主和绑定 | 在现有 Editor 配方内补所需资产契约 | UIHost 的 Canvas/层、输入所有者；ModalShell 内容槽与首次选择；ButtonShell 视觉/文字/图标槽 | Scene/Prefab 经 Editor API 保存；字段错误定位到资产、组件、字段；不通过全局 Find 自动补引用 |
| 旧容器视口修补 | 项目专属／排除，候选 C03 | 最近祖先 Canvas 与旧零尺寸父容器；每帧修正 offset | 通用原生模板直接采用正常 RectTransform 层级，不引入每帧布局补丁；未来出现独立需求再准入 |
| 列表、Toast、Loading、复杂导航 | 隔离候选 | 待真实共同消费点明确后确定 | 本轮不生成空壳，不以名称承诺可用 |
| 属性/Buff、奖励/背包/装备、通用战斗 | 隔离候选；业务领域继续归消费者 | 需原版规则、事务边界与两个独立需求支持 | 本轮合成战斗示例只验证共享框架，不能证明来源玩法正确或通用战斗已实现 |
| 来源图、来源节点身份、旧视图工厂、源 Tween/帧循环 | 排除 | 一次性转换器的来源证据与运行层分开 | 不进入公共包、模板及 Player；使用 Unity 原生输入、场景、动画和既定主流能力 |

## 首批实现安排

五层职责继续是 Domain、Gameplay、Services、Presentation、Bootstrap，不拆成五个通用包。counter 旧配方保持 seed-once 所有权；两个新消费者各自拥有规则、存档 DTO、用例与装配，只共享现有公共包及本轮通过准入的组件。

本轮优先补可失败的程序集边界守卫、有限按压反馈和三个基础资源的原生编辑契约。Foundation 已有接口与恢复语义先保留，只有新的实际失败测试证明缺口才修改。版本、资源生成身份、测试及 Player 结果以最终验收摘要为准，以上安排不等于已经实现或已通过。


## 其他项目的只读参考补充

本轮另收到八个既有工程的只读源码/历史验收抽查。完整来源、64 个文件身份及静态风险留在私有参考评审；这些历史结果不作为本轮新包运行证据，也不表示整工程迁移完成。公共实现采用独立代码与合成数据。

| 参考主题 | 本轮归属与判定 |
| --- | --- |
| 安全区求交、非零窗口原点、像素单位；长文字和人工编辑 | 补现有 UIHost/生成器与正反例，不复制上游 UIManager、单例或字符串路径 |
| 同帧按下松开、取消、旧回调、按住时打开弹窗 | 复用现有 Unity Button/CommandButton/有限反馈与作用域；不移植全局修改 InputSystem 设置的指针缓存 |
| 待领奖重开、重复领取、校验/保存失败前后不变量 | 数值战斗示例自有 Gameplay；益智移动/重置自有提交；不创建通用经济/事务引擎 |
| 构建前后 Assets 指纹、QA 存档隔离、无 Library 恢复 | 本轮两示例验收门；测试注入与 OS 输入分别记录 |
| 首差异和固定负载 | 预期失配必须失败，缺输入/结果为 not_run；没有性能基线不承诺改善百分比 |
| A*、复杂池、广告 SDK、Toast/Loading、农场与经营 | 后续候选，尚无本轮两个独立共同消费者，不作为模板默认 |
| 占位恢复工程、原版规则/美术/反编译代码 | 排除；不从静态可导入推断运行系统可用 |

设备移除与官方 InputSystem 适配仍是后续候选；当前明确验证的输入后端是锁定 uGUI 的 StandaloneInputModule。没有安装第二输入框架，不把未运行的后端记为通过。
