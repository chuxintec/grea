# 故障排查

先保存命令、版本、target、结构化错误和 run.json，凭据与原始私人路径不要贴入公开 issue。

| 症状 | 检查与处理 |
| --- | --- |
| 插件装上但没有 MCP | 新会话检查技能和工具发现；回读 session.package_root，确认没有同名旧注册；核对原生 target，不能运行另一 CPU/OS 包 |
| Runtime missing / 启动失败 | 核对 ZIP 校验与完整解压；纯文档包没有 Python。使用随包解释器，不临时改清单指向开发源码 |
| PROVIDER_UNAVAILABLE / UNSUPPORTED_HOST | describe-tool 回读 canonical ID 和 argv；为当前平台显式配置供应方。核心工具不要求所有 provider 全部可用 |
| INVALID_JSON / 中文输出异常 | UTF-8 请求文件与 --input；避免 cmd 引号/转义，Windows 路径可用正斜杠 |
| OUTPUT_EXISTS / PUBLICATION_FAILED | 选新路径；目标即使空目录也不覆盖。保留 stage；跨卷不使用复制覆盖伪装原子发布 |
| Case 读写等待 | 锁文件必须真实存在、不是链接；检查锁持有进程。不要删锁绕过并发；持有者退出后 OS 释放 |
| STALE_CANDIDATE / STALE_SOURCE | 候选或来源变了；按身份建立新 revision/Case，不沿用旧通过证据 |
| TIMEOUT / CANCELLED / OUTPUT_LIMIT | 检查日志和清理回执；Windows Job/POSIX group 仅清理所拥有进程。不宣称未知后代全部结束 |
| CLEANUP_INCOMPLETE | 先核对实际进程与管道，再决定重试；不把 capture_complete 记为 true |
| Editor/导入/构建失败 | 对正确隔离工程核对版本/包/许可和实际连接；生成成功不是 Editor 成功，详见 Unity指南 |

进一步契约与操作名见 [接口](接口与证据说明.md)，平台边界见 [安装](安装与平台.md)。缺桌面/Editor/许可证时明确 not_run 或 blocked，不用 mock 填补结果。
