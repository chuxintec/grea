# grea v2026.10.16-rc1

本版是预发行，产品、CLI 与插件版本统一为 `2026.10.16rc1`。

## 主要变化

- 首次提供完整 macOS arm64 插件：本地 stdio MCP、CPython 3.12.14、锁定依赖、核心工具与资源一起交付。安装后无需系统 Python、uv 或手工配置源码路径。
- 插件包含 8 个技能：路由入口与 7 个领域技能；支持 Codex 和 Claude Code。规范维护源统一为 `plugin/`，共享参考与领域参考按职责拆分。
- 现有 63 个工具 ID 与 20 个 MCP 操作保持兼容；工作流新增 `port` 模式、`cocos` 来源与 `native` 验收维度，明确跨引擎转原生 Unity 的边界。
- 新增数值战斗模板设计文档、证据链和合成示例，涵盖 Cocos 到 Unity、UI、Prefab、配置与框架提炼。它仍是设计提案，不是可生成的新游戏模板。
- 发布流程同时构建源码包、纯文档 Skill 包与完整平台插件；插件经过重复构建比较、隔离业务调用及逐文件身份校验，再与源码提交绑定并上传回读。

## 选择制品

| 附件 | 用途 |
| --- | --- |
| `grea-plugin-macos-arm64.zip` | Codex/Claude Code 完整插件，内置运行时和核心工具 |
| `grea-v2026.10.16-rc1.zip` | 完整源码使用包，供开发维护或从源码安装 |
| `grea-skill-v2026.10.16-rc1.zip` | 独立流程文档，不注册 MCP，执行工具时另装 grea |
| `plugin-acceptance-macos-arm64.json` | 本次完整插件的隔离调用验收 |
| `release-manifest.json`、`SHA256SUMS` | 源码、版本、附件身份与下载校验 |

安装步骤见[插件构建与安装](../Skill构建与安装.md)，校验与发布门槛见[自动发布](../Release自动发布.md)。旧源码版 MCP 注册与新插件不可同时作为同名入口；更新后应在新会话核对 `session.result.package_root` 和工具执行命令。

## 验收范围

完整插件针对 macOS arm64；Unity Editor、构建模块、商业插件和大型可选外部工具按需安装。Windows 完整插件、Unity/Player 运行和游戏一致性不属于本次插件发布验收。历史 Player 记录只适用于对应版本；本次发布工作流和随包验收回执提供本版的实际结果。
