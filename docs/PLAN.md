# beaver public release plan

This is a frozen distribution summary, not the maintainer's live task source.

Target: v0.6.0. Candidate: 0.6.0. Scope and acceptance boundaries are documented in [release scope](RELEASE-v0.6.0.md).

The release consolidates already verified project-development capabilities. Packaging, isolated artifact installation, relevant compatibility checks and exact GREA combination validation precede publication. Existing pinned consumers and transaction identities are preserved.

No new game features, universal recovery/runtime claims, production operations or global upgrades are included.
