# GREA 条件性恢复与审计脚本

日常安装与调用统一见 [使用说明](../使用指南.md)。具名操作优先，其余通过 run-tool 调用；本页只补充数值纹理、事件 schema 与 Laya 回归的专用契约。`bin/recovery` 保留兼容。当前依赖状态通过 GREA doctor 查询，历史验证不代表当前环境。

## 调用选择

| 需求 | 入口 | 成功判据与边界 |
| --- | --- | --- |
| 工具可用性/版本 | `registry_doctor` | 兼容统一 doctor；默认只查存在，--tool ID --probe 显式探测；--verify-frida-pair 单独校验配对，不附加设备 |
| Unity静态资产台账 | `unity_asset_ledger` | 调用 GREA 内唯一实现；参数以help为准 |
| 文本GUID依赖 | `unity_dependency_audit` | 有缺口返回1，输入错误2；不自动导入 |
| 原始浮点纹理 | `audit_numeric_texture` | 尺寸与字节数、f16/f32、端序、范围/非有限值；可与Unity导出原字节比较 |
| 有序事件差分 | `compare_events` | 先校验schema，再复用compare_traces；0相同、1首差异、2输入错误 |
| 任意字段JSONL差分 | `compare_traces` | 沿用已迁移的原接口，不强行转事件schema |
| Laya转换回归 | `laya_contract_audit` | 显式加载可信项目解析器；不复制转换器、不导入工程 |
| Unity实际资源回读 | `../tools/unity/audit/RecoveryRuntimeAudit.cs` | 通过已发现的Editor脚本接口调用，报告不等于视觉验收 |

## 数值纹理

```sh
/path/Games/grea/bin/recovery audit_numeric_texture /path/vat.raw --width 33 --height 46 --channels 4 --dtype f16 --candidate /path/unity-export.raw --output /path/new-report.json
```

宽高和格式来自原对象，不从扩展名猜。只支持无mipmap的紧密排列原始浮点数据；有mip链先按格式拆出指定层。输入文件不修改；报告必须新建，父目录须存在。遇到非有限值或candidate不一致返回1。只有源文件检查时candidate_equal为null，不冒称Unity回读通过。采样/sRGB/mipmap由C# Texture入口读取；是否符合该纹理用途由原始契约决定。

## 事件schema

每行JSON：`{"seq":1,"event":"hit","state":{"remaining":10}}`。seq须严格递增，event非空，state为对象；两侧默认精确比较seq/event/state，额外时间或随机字段用 `--field /rng`。不自动重排或对齐不同事件，不把浮点容差、业务常量或随机种子写进公共工具。原逻辑向量生成与C#采样仍属于项目适配。工具不启动原游戏或执行原版脚本。

```sh
/path/Games/grea/bin/recovery compare_events native.jsonl unity.jsonl --field /rng
```

## Laya回归边界

```sh
/path/Games/grea/bin/recovery laya_contract_audit --converter /path/project/Tools/convert_laya.py --mesh /path/model.lm --global-skin --particles /path/project/Tools/laya_particles.py
```

--global-skin 必须由源 SimpleSkinnedMesh 类型确定；普通蒙皮不要加。检查顶点/骨骼索引、全局索引不被重映射，及合成16帧粒子曲线不丢失。解析器现有流程仍含项目路径/数据约定，故不搬进 GREA宣称通用Laya转换器。

这些结构检查没有证明烘焙矩阵空间、渲染状态和最终姿态等价；它们是继续提炼转换器前的回归门槛，不能替代原场景GPU与逐帧对照。只有显式指定可信本地Python时才使用此入口，因为Python模块顶层代码可以有副作用。

## 测试

`python3 tests/test_p0.py` 从独立临时cwd测试两种数值格式、端序、差异、损坏输入、报告冲突、事件首差异及无效事件。真实项目证据由项目或外部记忆服务保存，不是本仓库的必需输入。本次未增加第三方依赖。
