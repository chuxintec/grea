# 制品与资源检查使用入口

通过 `list-tools`/`describe-tool` 选择工具，再使用 `run-tool` 或兼容 `legacy` 入口调用。常用 ID：`video_manifest`、`verify_payload_tree`、`unity_dependency_audit`、`unity_asset_ledger`、`image_alpha_audit`。工具 ID 与参数保持兼容。

完整调用、输入合同、范围限制和验收规则统一见 [资源审计与制品校验工具](../../plugin/skills/grea/references/资源审计与制品校验工具.md)。这些内容随整套 Skills 分发，不要求读取仓库手册。
