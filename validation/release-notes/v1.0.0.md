# GREA v1.0.0

状态：候选准备中，未发布。

收口五阶段技能、CLI/stdio MCP共享调度及已验证的精确provider维护。统一monkey0.7.0和beaver0.6.0组合，从打包制品隔离安装，并通过代表恢复选择、依赖交接、工程采用和构建/运行检查验证声明范围。发布以最终精确制品及验收报告为准。

历史日期版、旧tag及游戏固定候选不改号。新版本从日期序列转为三位数字，不按数字大小推断升级/降级；用户应按发布记录与兼容范围选择。既有工具ID、证据和partial/unsupported/not_run保持。

限制：monkey0.7不承诺完整业务恢复或全部视觉一致；Unity来源0.8开发线独立保留。beaver虚拟光标为有界备选，不推定全部真人并行/接管情形通过。原生引擎、可选分析器仍按任务显式准备；不依赖开发者私有目录。Windows原生及两平台安装以随包验收报告为准，Windows桌面/Unity/Player未实机验收。

分发为macos-arm64与windows-x64两完整插件包；本机启用与远端发布分开，不自动升级游戏或活跃插件缓存。Konanw市场后续登记固定版本目录与校验值，用户选择更新后另行启用；本轮不写市场缓存。
