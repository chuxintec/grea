# GREA v1.0.0

五阶段技能、CLI与stdio MCP共享调度，固定monkey0.7.0与beaver0.6.0的精确wheel。新增稳定组件的producer、包树、capabilities与有限操作适配；保留既有工具ID、退出码、partial/unsupported/not_run及历史固定候选。数值配置采用产品内JSON，输入方式、功能命名与工具消费者交接按随包技能执行。

完整插件提供macos-arm64与windows-x64两份ZIP，包含锁定Python、模块wheel、许可证与图标。平台原生打包、搬迁隔离、临时客户端安装、重复构建和公开CLI/MCP结果以随包验收报告为准。代表组合覆盖生成候选交接、采用计划、intake v5、构建计划及拒绝和代码依赖审计；plan成功不代表native apply/build/Player成功。未变组件的原生证明按其明确中性工程和实现身份复用。

历史日期版、旧tag及游戏固定候选不改号。新版本从日期序列转为三位数字，不按数字大小推断升级/降级。monkey0.7不承诺完整业务恢复或全部视觉一致；Unity来源0.8开发线独立保留。beaver虚拟光标为有界备选，不推定全部真人并行/接管情形通过。外部引擎与可选分析器仍按任务显式准备；Windows桌面/Unity/Player、视觉和游戏业务未实机验收。

远端发布与本机启用分别记录，不自动升级游戏或活跃插件缓存。Konanw市场后续登记固定版本目录与校验值，用户选择更新后另行启用；本轮不写市场缓存。
