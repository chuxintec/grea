## GREA v2026.10.27

本次重新发布统一了五阶段技能与正式执行模块，并修复了双平台插件构建和 Windows 调用检查。升级时请核对制品 SHA256 和 `source_revision`；日期版本号相同不代表安装的是这次重发的内容。

### 五技能工作流

- `grea` 负责阶段判断、证据边界与工具编排；`grea-research`、`grea-recover`、`grea-develop`、`grea-release` 分别承载调研、恢复、开发和交付。
- 换皮、Go 服务端、Unity/Cocos 开发与原版差异修复统一归入 `grea-develop`；旧工具 ID、工作流 mode、CLI/MCP 输入保持兼容。
- 全量技能文档完成职责与重复内容审计，76 篇整合为 70 篇。执行必需的合同、参考与最小示例位于技能分发范围内；安装后的技能不依赖源码仓库的 `docs/`。

### 正式模块与工具调用

- 双平台完整插件内置 monkey **0.6.0** 和 beaver **0.5.0** 的正式 wheel。`modules.lock.json` 固定各自 Release 下载地址、源码提交、字节数及 SHA256，运行时不追随浮动 latest。
- monkey 负责原包或冻结来源到独立候选；beaver 负责开发工程的结构、资源、JSON 配置、验证与构建。GREA 保留方法和薄转发，既有来源工具与工程工具继续按原 ID 调用。
- beaver 新增五个有限转发入口：`ui.inspect`、`ui.analyze`、`ui.repair-plan`、`wiring.plan`、`diagnostics.summarize`。具体执行以已声明能力、固定实现身份和请求合同为准；不会透传任意命令。
- provider 的 `partial`、`blocked`、`failed`、`not_run` 及实际修改记录如实保留。执行后消费校验失败不会被误报成未执行，也不会自动重放写入。

### 可靠性与公开内容

- CI 显式下载并打包锁定模块，修复预览插件遗漏执行模块的问题。
- 修复 Windows 测试中的绝对路径、HOME/USERPROFILE 和清单路径分隔符；插件失败诊断通过真正的模块入口运行。
- 显式 provider 状态目录不再触发不必要的用户主目录解析。框架审计从消费者程序集推导命名空间，移除真实项目名硬编码。
- 公开文档与验证摘要移除真实项目名、个人路径和会话身份；脱敏摘要标记清晰，原始证据哈希与公开文件哈希分开保存。

### 安装与验证边界

下载适合本机的完整插件 ZIP，并与同一 Release 的 `SHA256SUMS`、`release-manifest.json` 核对。插件包含可迁移 Python 运行时、五技能和两个固定模块；Unity/Creator Editor 及可选第三方程序仍需按任务准备。

核心工具可使用随包模块；独立模块安装、绑定和 `toolchain_check` 是另外的明确步骤。macOS/Linux 支持隔离模块安装；Windows 完整插件支持随包工具运行，独立模块安装仍受 POSIX launcher 限制。旧项目显式锁不会自动改成新版本。

最终双平台隔离、临时 Codex 安装发现及制品校验结果见本 Release 附件，均绑定实际源码提交。本版未新增完整游戏恢复、真实业务采用、Player 实玩或人工输入验收；可选依赖可用性、宿主热加载与业务完成不能互相替代。
