## 本次变更

- 新增 Windows x64 完整插件，自带锁定的 Python 3.12.14、核心依赖、stdio MCP 和全部 8 个技能。保留既有 CLI、工具 ID、别名与参数接口。
- 补齐 Windows 原生文件锁、无覆盖原子发布、Job 子进程归属和清理、UTF-8 输入输出，以及可选供应方的原生命令接入。
- 修复 AppContainer 中的 `NUL` 输入设备拒绝、规范盘符查询失败和 `0700` 临时目录缺少创建者 AppContainer SID 的问题。继续验证源码读取、安装写入、联网拒绝及进程清理；验收器只映射自有临时目录，不修改其他目录权限。
- 使用文档集中为六份核心指南与导航；补充按工具 ID 的证据索引，区分平台声明、合成样本、真实工具调用和游戏实机验证。
- 发布附件收敛为两个完整安装插件、分平台隔离/客户端报告、manifest 和 SHA256SUMS。退出独立 Skill ZIP 与自定义源码 ZIP；插件中的技能、参考、图标、许可和 `sync_skill.py` 保留。源码继续由 Git/GitHub 自动下载提供，历史 Release 制品保持原样。
- 发布流程分别在开发分支、实际 main 提交和正式标签执行门禁；两个平台必须来自同一提交，重复构建一致，上传后逐附件下载比对，再回读正式发布状态。

- 修复 Case 在系统时间精度不足或回拨时可能选择旧修订/旧验收结论的问题；在独占锁内分配递增顺序，保留既有记录和接口，并补充同时间与回拨回归。插件验收失败报告补充堆栈和状态响应。

## 验证范围

Windows x64 在 Windows Server 2022 原生 CI 验证核心回归、中文/空格路径、隔离后的 9 个真实核心工具、Case/revision、两份 stdio 启动配置、重复构建，以及 Codex 0.163.0 的临时安装、8 个技能和 21 个 MCP 工具发现。macOS ARM64 执行对应的完整插件门禁。客户端验收不发送模型请求。

Windows 11 桌面、Unity Editor/Player、GPU 性能和人工输入由本轮范围明确排除，状态为 `not_run`；原生 Claude 客户端未安装或验收。未测可选供应方不声明 verified。具体源码身份、包哈希和验收结果见附件 `release-manifest.json`、`SHA256SUMS` 及分平台报告。
