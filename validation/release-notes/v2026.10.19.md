## grea 能做什么

grea 是面向已发布游戏的取证、恢复与原生 Unity 转换工具集，提供统一 CLI、stdio MCP、8 个 Agent 技能和可复查的执行回执。功能覆盖包体/资源与代码证据、有限格式静态解析、配置/轨迹/表现检查、Unity 资产与依赖台账、受控工程和原生制作候选、Foundation/uGUI/Editor 薄胶水，以及 Case/revision、构建与交付身份管理。第三方解包/反编译、Unity Editor、.NET/Cecil 等能力按需准备；它不是一键万能转换器，工具通过不等于游戏可玩或原版一致。

## 安装与升级

下载对应的 `grea-plugin-macos-arm64.zip` 或 `grea-plugin-windows-x64.zip`，按 `SHA256SUMS` 与 manifest 核验后解压到新目录。完整插件自带锁定的 Python 3.12.14、核心依赖、MCP、全部技能、参考与许可证；无需配置源码路径。具体 Codex/Claude Code 命令与升级回退见 [安装指南](https://github.com/chuxintec/grea/blob/v2026.10.19/docs/安装与平台.md)。保留旧包，重启客户端后用新会话核对 session 版本、包路径和一次真实工具调用，再处理旧注册。

## 验证与限制

Release 自动流程从同一标签提交构建两个平台，检查原生核心/隔离工具、临时 Codex 安装发现、重复构建、来源/版本/验收身份及上传后逐附件下载比对。具体事实以本次 workflow、manifest、SHA256SUMS 与分平台报告为准。

Windows 范围为原生 Windows Server CI；Windows 11 桌面、Unity Editor/Player、GPU 与人工输入仍未实机验收。原生 Claude 客户端、游戏 GUI/音频/性能不因本维护包更新而新增通过结论。Mono 元数据检查不支持 IL2CPP，也不签发完整原生机制退出或可玩证明。
