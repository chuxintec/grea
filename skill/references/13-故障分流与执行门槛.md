# 故障分流与执行门槛

重复失败或测试与实玩冲突时，按症状选入口，先定位第一处缺口；不自动全量运行 doctor 或重做恢复。环境可疑时只核对相关工具，入口见 [工具清单](9-工具目录与准入.md)。

| 症状 | 先取得的证据 | 权威处理入口 |
| --- | --- | --- |
| 原界面资源似乎缺失/字段读不全 | 包哈希、导出索引、加载 getter、PPtr/MonoScript 与外部包 | [资源身份与类型树](2-资源逆向恢复.md)；不先自制替代 UI |
| 导出 C# 能编译但逻辑不对 | 方法体、metadata/方法地址、调用链与分支 | [代码恢复](12-工程重建与代码恢复.md)；区分空壳与实现 |
| MCP 零工具、主线程/构建超时 | 目标项目、Pipeline、编译/重载状态、run-id/进程/报告时间 | [连接与执行](11-Unity工具执行路线.md)；先查旧任务，勿盲重跑 |
| Prefab 激活但空白/缺图 | sprite.texture、图集、实际 Shader、相机与排序 | [实际显示](5-界面与交互.md#unity-原工程恢复的显示检查)、[接入回读](12-工程重建与代码恢复.md#shader-与-spine-接入回读) |
| Spine 局部、特效黑块或材质机制失效 | atlas/动画引用、活跃 Shader 属性、运行材质/遮罩 | [接入](12-工程重建与代码恢复.md#shader-与-spine-接入回读)、[特效排错](7-特效调度与流程.md#特效排错顺序) |
| 动画永不结束/短动画采不到中间帧 | 加载、焦点、timeScale、deltaTime、轨道/回调及事件时间 | [帧率前提](8-验收与协作.md#短动画与帧率前提)、[生命周期](7-特效调度与流程.md)；不改生产时长迎合夹具 |
| 任务、扣费、重入或重载异常 | ID/字段、可见与可执行条件、实际存档路径和起点 | [玩法](6-玩法与随机.md)、[奖励边界](7-特效调度与流程.md#奖励表现与流程边界) |
| 拖动滞后/松手继续转/截图有窗口但点击无效 | 输入队列、边沿、捕获、焦点、进程与构建ID | [输入与焦点](5-界面与交互.md)；不直接改灵敏度或删除生产门禁 |
| 规则连体但无线、粒子存在却无效果 | 关系锚点、运行资源键、活跃实例、粒子及清理事件 | [运行绑定与关系表现](7-特效调度与流程.md) |
| 命中卡顿/高内存 | 精确进程、堆/RSS、采样负载、分配/写盘/候选扫描 | [性能对照](22-性能优化与对照验证.md)；用有界测试，不并发重跑全套 |
| 单EXE可解压但无法启动 | 目标架构/后端、完整payload身份、实机日志 | [构建交付](23-构建输出与版本发布.md)；包体检查不替代实机 |
| GUID 未变但类型整理不达标 | 实际导入类型、旧新路径与动态键，是否仅套父目录 | [类型目录](20-标准工程目录与类型归类.md)、[迁移执行](17-Unity工程重构与资产治理.md) |
| 换皮风格相似但按钮形状不对 | 最新批准来源、本次是否指定页面独占裁片、实际制作输出 | [素材制作](21-换皮图生图与ComfyUI切图.md)；不混入已否定版本 |

## 工具执行的停线条件

发现目标/输入不匹配、关键引用或编译失败时，按 [执行契约](11-Unity工具执行路线.md#编辑与长任务) 暂停依赖步骤，独立工作继续。新证据才能支持再次尝试；旧 PASS 或外层超时都不足以下结论。调查检查点见 [工作节奏](4-工作节奏与证据门槛.md)。

历史案例与当时状态归 [经验导航](10-经验索引.md)，本页不维护项目进度。
